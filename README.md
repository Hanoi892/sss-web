# 동밤정 (Dong Bam Jeong)

베트남 밤문화 및 여행 정보 커뮤니티의 정적 콘텐츠 1차 버전.

- 4개 도시: 다낭, 하노이, 호치민, 나트랑
- 가라오케 및 마사지 각 도시별 메인 허브
- 개별 업소 공개 정보 페이지
- 골프/풀빌라/카지노 독립 랜딩
- 원본 이미지는 추후 사용자 제공 후 삽입
- SEO: 정적 페이지, 메타 태그, canonical, sitemap, FAQ

주의: 외부 공개 자료를 바탕으로 작성된 비교 콘텐츠이며 직접 검증/예약/실시간 가격을 보장하지 않습니다. Supabase 환경변수는 연동되어 있으나 현재 정적 콘텐츠에는 데이터베이스 호출이 없습니다.
